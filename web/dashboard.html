Resin calibration

How the printer turns grams into millilitres for the resin above. Set it once per resin; it travels in the profile.
Resin left, by weight
The marker on the vat says full or not. A scale says how much - and that is the number the low-resin warning and the per-model estimate actually work with.
Vat now weighs g = - ml left
(weight − empty vat - g) ÷ profile density. Vat differs? Weigh it
Density
Currently - g/ml - this is what turns the grams you weigh into ml.
Measured g of ml = - g/ml
Fill the vat to its marker, weigh it empty and full, and enter the difference against the vat size - or weigh a syringe. Changing this re-fits both samples below, so the calibration stays correct.
Weighed prints
Sample 1 estimated ml → weighed g = - ml
Sample 2 estimated ml → weighed g = - ml
Weigh the vat before and after a print and enter the difference. Two prints of clearly different size are what let the printer tell the model scaling apart from the fixed film that leaves on the plate every time.

Phone notifications

Messages you when a print finishes, pauses for low resin, or is canceled.
Messages go through the free CallMeBot gateway - press ? above for the one-time activation.
Create one in your Discord server: Server Settings > Integrations > Webhooks.

Boot animation

Pick which animation plays at power-on and press Save config. Show plays it on the printer's screen (idle only) - check the printer. Delete removes the file from the SD card.

3D previews

Models show a real, turnable 3D view once their slice data is prepared. A model prepares itself the first time you open it - this does the whole card in one go.
All models
About half a minute per model, and only while the printer is idle. Old flat thumbnails are removed as each model is prepared.

Backup & restore?

Requires TinyMaker Connect registration.
The backup holds every setting and the lifetime counters. With a backup on the SD card, the printer offers to restore it on the first boot after a full USB reflash.
