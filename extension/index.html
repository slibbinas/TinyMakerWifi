Browser extension

TinyMaker print status on your browser toolbar - progress on the icon, details and a dashboard link in the popup. Chrome / Edge.

Install (Chrome / Edge)

  1. Download the extension (.zip)
  2. Unzip it to a folder you will keep.
  3. Open chrome://extensions and switch on Developer mode (top-right).
  4. Click Load unpacked and pick the unzipped folder.
  5. Open the extension's Options and set your printer address (default tinymaker.local). Theme lives there too.

A one-click Chrome Web Store version is on the way; this manual install works today.
