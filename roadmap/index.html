TinyMakerWiFi - Roadmap

Where the WiFi / wireless-upload / OTA firmware for the open-source TinyMaker MSLA resin printer is headed. Updated at each release.

Where we are

0.18.3 is the last release with new features before 1.0.0. New features are frozen as of 24 September 2026; from here on only fixes go in, until 1.0.0. The automatic self-update is on 0.18.3, and every version is one press away in the dashboard's Update → version picker (see the releases for what each one adds).

Delivered up to 0.16.2

The foundation, on every printer since 0.16.2:

  • WiFi that reconnects on its own after a router dropout, and wireless model upload straight from PrusaSlicer.
  • Power-loss resume - after an outage the printer offers to pick the print back up from where it stopped, or to safely lift the plate off a stuck print, and you can answer that from your phone. Field-tested with real power cuts.
  • A print-aware screen saver - dims the idle screen, moves the printer name and IP around (no burn-in), and shows live progress while printing.
  • Grouped settings and a Statistics screen (print hours, UV time, boot info), with Update kept visible and badged when something is available.
  • Long jobs never freeze a screen - unpacking, flashing and card work all report progress, and every open dashboard sees the same thing.
  • "Why did it restart?" diagnostics after an unexpected reboot, including the layer it was on.
  • Light and dark themes across the dashboard.

Delivered 0.17

The release that turned the model preview into a real 3D view and gave every resin its own recipe - on the automatic update since 0.17.6:

  • Named resin profiles - a profile is the whole recipe for one resin: exposures, base layers, all four lift settings, density and layer height. Switching resin is one press instead of ten fields. Four profiles are built into the firmware - two resins at both layer heights - so the picker is never empty, and more install from the published library.
  • Resin left, by weight - weigh the vat once empty, then weigh it full, and the printer works out the millilitres left instead of assuming a full vat. A per-resin calibration makes the "will this print fit" warning a measured number - and the two built-in Fast profiles ship already calibrated from weighed prints, so the number is right before you ever put the vat on a scale.
  • The model preview is a real 3D view - it used to stack 36 slices like pancakes, which made anything detailed unreadable. Now the printer's own layers become a surface drawn by your browser's GPU, at the printer's native resolution and with every layer of the model. A slider cuts the model at any height.
  • The growing print is visible in every browser, not only in the one that opened Preview first - open the dashboard on a second phone mid-print and the model is already there.
  • Print time per model in the card list, recomputed from the resin profile in force - switch profile and every row updates.
  • Exposure in tenths of a second, which fast resins need, with the print-time impact shown before you save.
  • Flat-print guard - a clear warning when the slicer's layer height is not the one the printer is set to, instead of prints silently coming out flat.
  • Marking a defect on the model - tap the preview where a print went wrong and the mark carries the height in millimetres, the layer number and the build, so a report says where it failed rather than "it failed".
  • The printer says when a file is being sent to it, so a phone that looks idle is no longer a mystery, and a push message tells you when power came back.
  • The browser slicer can live on the SD card, so a printer with no internet still slices, and the dashboard checks for a newer module by itself.
  • The browser slicer places the part for you - one Fit button, with two switches for how: lay it on its widest side or search for the tilt that needs the fewest supports (the PrusaSlicer way), and keep your size or make it as large as the plate allows. Lay flat, Flip, Tilt and Rotate are there when you want to decide yourself, then six settings for supports, strength, placement, tip, raft and smoothing. The raft is counted in layers (2, 3 or 6; default 3), because layers are what decide whether the pad grips. On for everyone since 0.17.6.
  • The plate knows where the top and the bottom are - the manual jog stops at the ceiling instead of grinding into it, touching the endstop is a homing ("Plate is home"), and a pause lift asked for at the ceiling no longer drives the plate down into the part.
  • Adjustable pause lift height for inspecting a print, and a dry run that no longer sends the plate to the ceiling.
  • Everyday polish - newest model on top of the card list, actions that appear under the mouse on a desktop, a wider preview window, buttons that show they were pressed, and a 24-hour clock.

Under the hood: about 60 KB of flash reclaimed, checkpoints written once per layer instead of twice (kinder to the card), writes accepted only from the printer's own dashboard, and a self-update that checks what it downloads before it flashes anything (signed updates since 0.18).

Just shipped 0.18

Updates that work wherever you are, crash reports that find the bug, and a few dashboard touches:

  • Self-update no longer depends on GitHub's certificate - in some regions GitHub serves a different one, and printers there could not update ("Version check failed"). Each update now carries our own signature, which the printer checks before installing, so the region and the printer's clock no longer matter.
  • Crash reports that point at the line - after a crash the printer sends an anonymous backtrace and the fingerprint of the exact build, so a rare fault is found instead of guessed at. The first report already found a start-up crash, fixed in 0.18.2. Opt-out, no personal data.
  • Light, dark or system theme - three icons in the dashboard header; System follows your phone or computer.
  • A browser extension that shows print progress on the toolbar, linked from the dashboard header until it is installed.
  • Your own links in the header - a links.json file on the SD card adds them next to Manual and Feedback, handy for a shop or a school.
  • Getting started without PrusaSlicer - the built-in browser slicer is enough; PrusaSlicer stays an option.

Feature freeze 0.18.3 → 1.0.0

Right now the focus is proving 0.18.3: collecting feedback from early testers and fixing what turns up. No new features until 1.0.0 - fixes ship as 0.18.x (see the releases for what each one fixes) until it runs quiet.

On the way

  • TinyMaker Connect - a community platform for sharing print-ready models straight to the printer.

Toward 1.0.0

1.0.0 is 0.18.3 with its fixes, promoted once it has proven itself: two weeks with no serious findings, running on at least three printers, the smoke tests and the self-update path passing on the same build, a security review, and the manual and README matching the release.

After 1.0.0

Once 1.0.0 lands, the community will help shape what comes next - you'll be able to vote on priorities in the Facebook group. The poll sets the direction; final calls on what actually ships stay with the maintainer.

Already planned for 1.1:

  • Several remembered WiFi networks - take the printer to a show, a workshop or a friend's place and back home without setting WiFi up again.
  • An “erase everything for a new owner” reset - the WiFi password and every stored key go too, before you sell or lend the printer.
  • A trash bin for models - deleting becomes instant, and the wrong model comes back with one press.
  • The last print, marked in the SD list - which model ran last and how it ended.
  • Hidden card entries explained - a damaged or oddly named model can still be found and removed.
  • A real Stop while slicing in the browser.
  • Sharper thin supports - the slicer stops sending grey levels too dim to cure the resin, a threshold measured on this printer.
  • A faster 3D view - drawn only when something actually changes, so turning and cutting the model stays quick, and closed cut faces in the slicer view.
  • Sharing resin profiles through TinyMaker Connect.
  • A web flasher that retries slower when the first attempt times out.
  • More security hardening of the dashboard.

Got an idea? The vote opens with 1.0.0 - and the feedback form in the dashboard is open any time.

Contributing

Small fixes, beta testing and bug reports are all first-class help. See CONTRIBUTING.md, or just send a note through the feedback form in the dashboard - 30 seconds, no account.
